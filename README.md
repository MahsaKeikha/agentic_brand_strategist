# Agentic Brand Strategist

F121 of the Agentic AI Library. A multi-agent brand strategy system for evidence-grounded positioning, audience insight, messaging architecture, competitive differentiation, and human-reviewed brand recommendations.

## Agents
- Research Agent
- Audience Agent
- Positioning Agent
- Messaging Agent
- Review Agent

## Run
```bash
python run.py
```

## Safety
Recommendations are decision support. Claims require evidence, uncertainty is surfaced, and consequential publication remains human-approved.
